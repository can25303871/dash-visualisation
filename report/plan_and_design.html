Plan and design

Plan for project

  • Find and pick a dataset.
  • Use pandas to extract and manipulate data for graphing.
  • Use plotly to plot graphs.
  • Make a webpage and fill it with information about the dataset.
  • Display the plotly graphs on the webpage.
  • Use dash to create a web app allowing the user to filter data.
  • Host this web app on render.com and display it on the webpage.
  • Make a form on the webpage and link it to a firebase realtime database.
  • Display the results of the form on the webpage using chart.js after the user submits the form.

Technologies in use

Pandas: to work with the csv files. I can use pandas for basic data manipulation, like reading in the data, and also for data cleaning and more advanced use cases. My data is split across several csv files, one file contains player and manager names and positions, one has player and manager names along with detailed statistics on their games, one has team names. I will need to combine these into one large dataframe, which I can use for graphing. Pandas seems to be the best option for this.

Plotly: to generate my plots. It has an extensive array of options for things like graph types and display modes. Interactivity is also very easy to implement.

Numpy: allows me to generate trendlines from my data. I can then plot these trendlines using plotly.

Dash: a library that builds on plotly, and allows for far more interactivity in my charts, such as filtering data. One downside is that in order to be used on an existing webpage (i.e. instead of running in a local server on its own), it has to be hosted externally.

Render.com: the external hosting site I will be using for my dash app. They offer a free tier which, although it has limitations, was still the best I could find.

Github: render.com requires files for the app to be on a github repository.

Firebase realtime database: for my form. It includes real-time data synchronisation, meaning when a user submits a form, the data is instantly updated in the database, and any connected client (e.g., the webpage displaying the chart) is immediately notified of the changes. It's never offline and always up to date.

Chart.js: to display the results of the forms. Chart.js provides many options for creating and formatting charts.

Use Case Diagram

My website is designed to be used by footallers, managers, analysts working for clubs, fans, and FPL users.

Actor Description
Footballer View statistics on themselves and other players.
Manager or Analyst View statistics on their own players and players they are looking to sign.
Fan View statistics on players, fill out form and view results.

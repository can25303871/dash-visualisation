Meeting the brief

Video


Dash app: When app.py is run, it generates a local instance of the dash app, which works perfectly within its own webpage. The issue is that it can't be included in another webpage, for example using iframes. To solve this the app is hosted externally on render.com and the iframe contains the URL. Render required me to push the code for my app to a github repository https://github.com/can25303871/dash-visualisation. This code contains a direct link to the original dataset, which is updated weekly, which can be done as the external server will always have an internet connection. Because it links directly to the original data source, I need to perform data extraction and manipulation within the app file. I simply copied the code from "data_extraction_and_manipulation.py" . Display of the dash charts: By default, the local chart is displayed. My javascript (update-graphs.js) checks if there is an internet connection. If there is, it loads the external app. This can come with a delay, owing to the capabilities of the free render hosting.
